# Study Schedule

## Weekly Schedule Template

### Monday: Introduction to New Topic
- **Time:** 1-2 hours
- **Activities:**
  - Read lecture slides
  - Review study guide section
  - Take notes on key concepts
  - Identify areas needing clarification

### Tuesday-Thursday: Deep Dive
- **Time:** 2-3 hours per day
- **Activities:**
  - Practice commands
  - Work through examples
  - Read related documentation
  - Experiment in lab environment
  - Review previous topics

### Friday: Practice and Review
- **Time:** 2-3 hours
- **Activities:**
  - Practice exercises
  - Review week's topics
  - Test understanding
  - Prepare questions

### Weekend: Lab Work
- **Time:** 4-6 hours
- **Activities:**
  - Work on lab assignment
  - Test configurations
  - Troubleshoot issues
  - Document progress

## Daily Study Routine

### Morning (30-60 minutes)
- Review previous day's notes
- Read new lecture material
- Quick command practice

### Afternoon (60-90 minutes)
- Deep dive into topic
- Practice commands
- Work on exercises

### Evening (30-60 minutes)
- Review day's learning
- Plan next day
- Quick reference review

## Study Techniques

### Active Learning
- **Practice commands** - Don't just read
- **Experiment** - Try variations
- **Break things** - Then fix them
- **Teach others** - Explain concepts

### Note Taking
- **Take notes** - Write down key points
- **Use examples** - Include command examples
- **Create summaries** - Condense information
- **Review regularly** - Don't let notes pile up

### Practice
- **Hands-on** - Use virtual machines
- **Repeat** - Practice commands multiple times
- **Variations** - Try different approaches
- **Real scenarios** - Apply to lab assignment

## Time Management Tips

1. **Set specific times** - Schedule study time
2. **Remove distractions** - Focus during study
3. **Take breaks** - Don't study for hours straight
4. **Prioritize** - Focus on important topics
5. **Be consistent** - Regular study beats cramming
