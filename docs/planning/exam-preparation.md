# Exam Preparation Guide

## Exam Overview

**Type:** Written Exam  
**Weight:** 3.5 HP  
**Format:** Theoretical examination

   - PAM
   - sudo configuration

2. **Process Management**
   - Process states
   - Signals
   - Process priorities
   - Process control

3. **Storage**
   - Device naming
   - Filesystems
   - Partitioning
   - Mounting

4. **Booting and systemd**
   - Boot process
   - Init systems
   - systemd services
   - Service management

5. **Software Management**
   - Linux distributions
   - Package management
   - APT/dpkg
   - Repositories

6. **Bash Scripting**
   - Variables
   - Conditionals
   - Loops
   - Functions

7. **Network Configuration**
   - IP addressing
   - DHCP vs Static
   - DNS resolution
   - Network tools

8. **Mail Servers**
   - SMTP, IMAP, POP3
   - Mail flow
   - Server components

9. **Scheduling**
   - Cron
   - Anacron
   - systemd timers

10. **Logging**
    - Syslog

    - Log management

11. **Troubleshooting**
    - Documentation
    - Log analysis
    - Common issues

12. **Security**
    - SSH
    - Authentication
    - Service security
