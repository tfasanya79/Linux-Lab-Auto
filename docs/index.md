# Linux Administration Course

Welcome to the Linux Administration (IT387G) course documentation!

This web-based documentation system provides comprehensive study materials, lab assignment guides, and quick references to help you succeed in the course.

## Course Overview

**Course:** Linux Administration (IT387G) - 7.5 HP  
**Institution:** University of Skövde  
**Term:** Spring 2026

### Course Structure

- **Lab Assignment (4 HP)**: Practical setup of Debian Linux server environment
- **Written Exam (3.5 HP)**: Theoretical examination

### Learning Objectives

After completing this course, you should be able to:

- Describe the fundamental mechanisms in Linux
- Describe and discuss the area's development and central concepts
- Use tools such as schedulers and configuration management software
- Install, configure, and document a Linux system

## Getting Started

1. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Start the Server:**
   ```bash
   python start-server.py
   ```
   Or use:
   ```bash
   mkdocs serve
   ```

3. **Open in Browser:**
   Navigate to `http://localhost:8000`
